## 部署

这是无构建步骤的 Cloudflare Pages 项目。将更新提交到现有仓库的生产分支，由原有 Pages 集成部署。
保留现有 DB 绑定和运行时变量：SESSION_SECRET、ADMIN_EMAILS、RESEND_API_KEY、EMAIL_FROM、SITE_NAME。
不需要重新建库，也不需要清空或重置数据库。不要为此次更新重新执行初始化 SQL。
未引入 wrangler.toml 或替换既有 Cloudflare 控制台配置。

## 验证

36 项前端逻辑回归、17 项后端 SQLite/D1 适配器回归通过。
五个页面 × 三种语言 × 电脑／手机共 30 组布局检查通过，无横向溢出或空白翻译。
浏览器实测了手机菜单、注册弹窗滚动及键盘关闭、会员编辑／语言切换／保存、读取失败保护。
